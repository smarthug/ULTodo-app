# ULTodo — はじめての方向け紹介

ULTodo は、毎日「何をやるべきか」で迷う時間を減らすための個人向けタスク管理アプリです。

多くの TODO アプリは、タスクをたくさん登録し、分類し、管理することに力を入れています。ULTodo が重視するのはその逆です。頭の中のことをいったん全部出し、その中から本当に今日やる少数のタスクだけを選び、静かに実行する流れを作ります。

## ULTodo が助けること

- 思いついたタスクをすばやく書き出す
- タスクを「緊急か」「重要か」で整理する
- 今日やることを少数に絞る
- ポモドーロタイマーで集中して進める
- データを自分の端末内だけに保存する

## 基本の流れ

1. **Brain Dump** で、頭の中のタスクを全部書き出します。
2. **Matrix** で、緊急度と重要度に分けて優先順位を整理します。
3. **Today** で、今日集中するタスクを少数だけ選びます。
4. **Pomodoro** で、時間を区切って実行します。
5. **Settings** で、集中タスク数やタイマー時間を自分に合わせます。

## 特徴

### 1. 「今日やること」を少なくする

ULTodo は、長いタスクリストを見せ続けるのではなく、今日取り組む短い集中リストを中心にします。初期設定では 3 件に絞られているため、朝から選択に疲れにくくなります。

### 2. 優先順位を目で見て動かせる

アイゼンハワー・マトリクスを使って、タスクを「緊急・重要」「重要だが緊急ではない」などに分類できます。ドラッグ＆ドロップで動かせるので、優先順位の整理が直感的です。

### 3. 実行まで同じアプリで完結する

タスクを選んだあと、別のタイマーアプリに移動する必要はありません。ULTodo にはポモドーロタイマーがあり、集中時間と休憩時間を切り替えながら作業できます。

### 4. オフラインで使える

Phase 1 の ULTodo はローカル専用です。アカウント、クラウド同期、サーバーはありません。タスクデータはブラウザ内の IndexedDB に保存されます。

## 向いている人

- 毎朝、何から始めるかで迷いやすい人
- タスク管理ツールを使ってもリストが増えすぎてしまう人
- 個人の集中用に、チームツールとは別の場所がほしい人
- クラウド同期やアカウントなしで使いたい人
- 「たくさん管理する」より「少なく選んで終わらせる」ことを重視したい人

## 現在の範囲

ULTodo は現在、ローカル専用の MVP として実装されています。Today、Brain Dump、Matrix、Pomodoro、Settings の 5 つの画面があり、スマートフォン幅とデスクトップ幅の両方に対応しています。

一方で、認証、クラウド同期、共同編集、通知、カレンダー連携などは Phase 1 の対象外です。ULTodo はまず、ひとりのユーザーが自分の端末で集中するための小さく静かな道具として設計されています。

## 一言でいうと

ULTodo は、タスクを増やすためのアプリではありません。**今日やることを減らし、深く終わらせるためのアプリ**です。
